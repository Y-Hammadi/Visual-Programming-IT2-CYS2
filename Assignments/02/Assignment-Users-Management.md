## Task 1: Add Users Management to the Clients Management System

**Task:** Extend the existing `Clients Management System` project by adding a new section for managing users, following the same approach and project structure used to implement the Clients Management section during the lecture.

### Requirements

1. Create a new section for **Users Management**.
2. Implement the following operations:

   - **Add User:** Add a new user.
   - **Display All Users:** Display all registered users in an organized format.
   - **Update User:** Find and update an existing user's information.
   - **Delete User:** Find and delete a user.

3. Add a new **Users Management** option to the main menu.
4. Create the necessary classes and screens following the existing project structure.
5. Make sure all existing Clients Management operations continue to work correctly.

### Implementation Guidelines

- Continue working on the existing project. Do not create a new project.
- Follow the same coding style and organization used in the Clients Management implementation.
- Reuse existing methods and components whenever possible.
- Maintain a clear separation between Clients Management and Users Management.

### Submission

Submit the updated project source code.

Be ready to demonstrate the new Users Management section and explain how you implemented its operations while maintaining the existing project structure.
